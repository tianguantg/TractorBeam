# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository.
Do not open a public issue for a suspected vulnerability until a maintainer has
confirmed that disclosure is safe.

Include the affected version, platform, reproduction steps, and the smallest
sanitized diagnostic extract that demonstrates the problem. Do not include Join
Codes, Session Credentials, Resume Keys, Connection IDs, Path Tokens, Steam
identities, access tokens, private keys, or local paths containing usernames.

## Diagnostics

Review exported diagnostics before sharing them. If private vulnerability
reporting is unavailable, open a public issue containing no sensitive data and
ask the maintainers to provide a private contact channel.
